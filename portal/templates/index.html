About

NexusPlay is a unified platform integrating diverse, complex local game engines and artificial intelligence simulators into a single, cohesive dashboard. Designed for researchers and gamers alike, it bridges the gap between disparate Python applications, 3D renderings, and web services, allowing you to fluidly shift between football management and massive AI sandbox battles.

Architecture

The system operates using an asynchronous local web micro-server built with Flask. The portal acts as the presentation layer, relying on JavaScript Fetch APIs to send launch payloads to the backend.

When a launch is requested, the Python orchestrator utilizes subprocess.Popen to spawn detached processes. This decouples the 3D rendering engines (such as Panda3D) and secondary web services (the Football Manager app) from the main thread, routing execution within distinct working directories seamlessly.
